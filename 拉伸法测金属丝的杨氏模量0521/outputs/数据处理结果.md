# 拉伸法测金属丝的杨氏模量数据处理结果

## 处理依据

- 直接测量量按 PPT：A 类不确定度取 ΔA = 1.05σ；B 类不确定度取仪器精度的一半；合成不确定度 u = sqrt(ΔA² + ΔB²)。
- 米尺不确定度取 0.5 mm，即 0.0005 m；螺旋测微器不确定度取 0.005 mm。
- 最小二乘拟合使用 b 为横坐标、m 为纵坐标；用于计算 E 时将斜率从 kg/cm 换算为 kg/m。

## 最小二乘线性拟合

- 拟合方程：m = a + k b = 0.01089 + 0.42724 b，其中 b 的单位为 cm，m 的单位为 kg。
- 截距：a = 0.01089 ± 0.00330 kg
- 斜率：k = 0.42724 ± 0.00068 kg/cm = 42.7235 ± 0.0678 kg/m
- 残差平方和：0.000158467
- Pearson's r：0.999992
- R²：0.999985
- 调整后 R²：0.999982

## 杨氏模量与不确定度

计算公式：

E = 8gDLk / (πd²l)

不确定度传递：

uE/E = sqrt[(uD/D)² + (uL/L)² + (uk/k)² + (2ud/d)² + (ul/l)²]

- E = 1.9412e+11 Pa
- uE = 6.5797e+09 Pa
- 相对不确定度：3.39%
- 最终结果：E = (1.94 ± 0.07) × 10^11 Pa
