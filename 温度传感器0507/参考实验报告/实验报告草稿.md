## 一、实验目的

1. 了解半导体热敏电阻和晶体管 PN 结温度传感器的基本测温原理。
2. 测量热敏电阻阻值、PN 结正向电压随温度变化的关系。
3. 作出热敏电阻的 `1/T-lnR` 关系图和 PN 结的 `T-U` 关系图，并由图线求出热敏电阻材料常数 `B`、PN 结温度系数 `k` 和禁带电压参数 `Ug`。

## 二、实验仪器

温度传感器实验装置、半导体热敏电阻、晶体管 PN 结温度传感器、加热油浴、温度采集系统、LabVIEW 温度采集程序、计算机等。

## 三、实验原理

### 1. 半导体热敏电阻

本实验所用热敏电阻为负温度系数热敏电阻，即温度升高时电阻值减小。其阻值与绝对温度之间近似满足

`R_T = A exp(B/T)`

式中，`R_T` 为温度为 `T` 时的电阻，`T` 为绝对温度，`A` 和 `B` 为与材料及结构有关的常数。两边取自然对数得

`ln R_T = B(1/T) + ln A`

因此，以 `1/T` 为横坐标、`lnR` 为纵坐标作图，应近似得到一条直线，直线斜率即为热敏电阻材料常数 `B`。热敏电阻温度系数为

`alpha_T = (1/R_T)(dR_T/dT) = -B/T^2`

### 2. PN 结温度传感器

在一定恒定电流条件下，PN 结正向电压随温度升高近似线性下降，可写为

`U = kT + Ug`

式中，`T` 为绝对温度，`k` 为温度系数，`Ug` 为将图线外推到 `T = 0 K` 时的截距。若用摄氏温度 `t` 表示，也可写为

`U = kt + b`

其中斜率仍为温度系数，单位可写为 `V/K` 或 `V/℃`。

## 四、实验步骤

1. 将热敏电阻和 PN 结温度传感器放入加热油浴中，并使其与测温铂电阻尽量靠近，以减小温度差。
2. 打开 LabVIEW 温度采集程序，设置文件保存路径、采样参数和数据记录按钮。
3. 从室温附近开始缓慢升温，记录温度、热敏电阻阻值和 PN 结电压等数据。
4. 按实验要求约每隔 `2 ℃` 选取一个数据点，整理成数据表。
5. 将温度 `t` 化为绝对温度 `T = t + 273.15`，计算 `1/T` 与 `lnR`。
6. 分别作 `1/T-lnR` 图和 `T-U` 图，用线性拟合求出相关参数。

## 六、作图与参数计算

由整理后的散点图可见，低温段 `27.007 ℃` 和 `28.989 ℃` 两点偏离整体趋势较明显。按实验原理，NTC 热敏电阻应随温度升高而阻值减小，PN 结正向电压也应随温度升高而减小。但实验数据中，`28.989 ℃` 到 `30.986 ℃` 时热敏电阻阻值和 PN 结电压反而增大，这与两种传感器的物理规律不一致。分析认为，这两个点很可能来自不同采集段拼接、升温起始阶段数据未稳定、传感器与油浴尚未达到热平衡等原因。因此，为比较异常点对结果的影响，分别进行“全数据拟合”和“剔除异常点后拟合”两种处理。

### 1. 热敏电阻

根据数据作 `1/T-lnR` 关系图。

若采用全部 32 个数据点，线性拟合结果为

`lnR = 3683.2576(1/T) - 4.6575`

相关系数：

`R^2 = 0.9864`

由直线斜率可得

`B = 3683.26 K`

剔除 `27.007 ℃` 和 `28.989 ℃` 两个异常点后，线性拟合结果为

`lnR = 3873.097(1/T) - 5.21383`

相关系数：

`R^2 = 0.9967`

由直线斜率可得

`B = 3873.10 K`

可见剔除异常点后相关系数明显提高，说明剩余数据与热敏电阻理论关系符合得更好。因此后续结果采用剔除异常点后的拟合参数。

取 `t = 30.986 ℃` 附近作为低温端代表点，则 `T = 304.136 K`，热敏电阻温度系数为

`alpha_T = -B/T^2 = -3873.10/(304.136)^2 = -0.0419 K^-1`

即

`alpha_T = -4.19 %/℃`

这说明热敏电阻对温度变化较灵敏，且温度升高时阻值下降。

### 2. PN 结温度传感器

以摄氏温度 `t` 为横坐标、PN 结正向电压 `U` 为纵坐标作图。

若采用全部 32 个数据点，线性拟合结果为

`U = -0.002533704 t + 0.563837235`

相关系数：

`R^2 = 0.9858`

因此 PN 结温度系数为

`k = -0.002533704 V/℃ = -2.534 mV/℃`

若改用绝对温度 `T` 为自变量，拟合式为

`U = -0.002533704 T + 1.255918583`

由截距可得

`Ug = 1.256 V`

剔除 `27.007 ℃` 和 `28.989 ℃` 两个异常点后，线性拟合结果为

`U = -0.002645539 t + 0.571594692`

相关系数：

`R^2 = 0.9941`

因此 PN 结温度系数为

`k = -0.002645539 V/℃ = -2.646 mV/℃`

若改用绝对温度 `T` 为自变量，拟合式为

`U = -0.002645539 T + 1.294223800`

由截距可得

`Ug = 1.294 V`

同样可以看出，剔除异常点后相关系数增大，说明拟合直线与实验数据更一致，故最终采用剔除异常点后的 PN 结参数。

两种处理方式的主要结果比较如下：

| 处理方式 | 热敏电阻 B/K | 热敏拟合 R^2 | PN 结 k/(mV/℃) | PN 拟合 R^2 | Ug/V |
|---|---:|---:|---:|---:|---:|
| 全部数据 | 3683.26 | 0.9864 | -2.534 | 0.9858 | 1.256 |
| 剔除 27.007 ℃、28.989 ℃ | 3873.10 | 0.9967 | -2.646 | 0.9941 | 1.294 |

## 七、实验结果

1. 热敏电阻的 `lnR` 与 `1/T` 基本呈线性关系。剔除低温异常点后，拟合得到材料常数  
   `B = 3873.10 K`。
2. 室温附近热敏电阻温度系数约为  
   `alpha_T = -4.19 %/℃`。
3. PN 结正向电压随温度升高而近似线性下降，拟合得到  
   `k = -2.646 mV/℃`。
4. PN 结温度传感器外推得到的禁带电压参数为  
   `Ug = 1.294 V`。

## 八、结果分析与讨论

由实验数据可以看出，热敏电阻阻值总体随温度升高而迅速减小，符合 NTC 热敏电阻的基本特性。将数据转化为 `lnR` 与 `1/T` 后，散点大致分布在一条直线附近，说明实验温度范围内热敏电阻可用指数关系描述。拟合得到的 `B = 3683.26 K` 位于常见热敏电阻材料常数范围内，结果较合理。

PN 结正向电压随温度升高而下降，图线近似为直线，说明在恒定电流条件下 PN 结具有较好的线性温度特性。拟合斜率为 `-2.534 mV/℃`，表示温度每升高 `1 ℃`，PN 结正向电压约减小 `2.534 mV`。

实验中低温段 `27.007 ℃` 和 `28.989 ℃` 两个点偏离较明显。它们不仅偏离拟合直线，而且与热敏电阻和 PN 结的温度变化趋势相矛盾，说明其偏差不只是普通随机误差。可能原因是低温数据和后续升温数据来自不同采集段拼接，或升温起始阶段温度尚未稳定，传感器与油浴之间未达到充分热平衡。剔除这两个点后，热敏电阻拟合相关系数由 `0.9864` 提高到 `0.9967`，PN 结拟合相关系数由 `0.9858` 提高到 `0.9941`，说明剔除后数据更符合理论模型。

实验误差主要可能来自以下几方面：第一，传感器与标准测温铂电阻在油浴中的位置不完全相同，导致二者实际温度存在差异；第二，升温过程中油浴温度变化较快，传感器存在热响应滞后，未完全达到热平衡时读数会偏离真实值；第三，数据采集时低温段与升温段可能存在拼接差异，导致个别点偏离拟合直线；第四，仪器分辨率、接触电阻及导线连接也会带来一定误差。

改进方法包括：升温过程尽量缓慢，在每个温度点附近等待读数稳定后再记录；使待测传感器与标准温度计紧贴并固定位置；重复测量并取平均值；绘图时对明显异常点进行检查，避免由误读或未稳定数据影响拟合结果。

## 九、实验结论

本实验测量了半导体热敏电阻和 PN 结温度传感器的温度特性。实验结果表明，热敏电阻阻值随温度升高明显减小，`lnR` 与 `1/T` 近似满足线性关系；PN 结正向电压随温度升高近似线性减小。考虑到低温段两个异常点与物理规律不符，最终采用剔除异常点后的拟合结果，求得热敏电阻材料常数 `B = 3873.10 K`，PN 结温度系数为 `-2.646 mV/℃`，外推得到 `Ug = 1.294 V`。两种传感器均表现出明显的温度响应特性，其中热敏电阻灵敏度较高，PN 结传感器线性较好。
